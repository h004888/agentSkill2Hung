# Agent Skills for Superpowers

Tập hợp các skills mở rộng cho Superpowers agent, giúp tự động hóa các tác vụ phát triển phần mềm.

## Skills

### ascii-diagram
Chuyển đổi mọi nội dung thành ASCII diagram để visualize trong terminal. Hữu ích cho việc tạo use-case, sequence, UI flow, data flow, workflow ngay trong terminal.

### interviewing-for-srs
Hỗ trợ phỏng vấn stakeholders, thu thập yêu cầu BA và hoàn thiện tài liệu SRS với các phần: product overview, actors, use cases, software features, screens, non-functional requirements, business rules.

### scene-by-scene
Debug bugs và investigate errors bằng narrative format theo từng bước từ action của user đến điểm failure.

## Sử dụng

Các skills này được load tự động khi cần trong quá trình làm việc với Superpowers agent.
